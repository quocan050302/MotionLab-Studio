3. HOW TO RUN ON ANY OTHER NICHE (GENERAL-PURPOSE CLI)
------------------------------------------------------
Create a standard job JSON (e.g. jobs/my_tutorial.json) with ordered `sources` (1..N clips of
any FPS/sample rate), `intended_story`, `niche_hint` (tutorial, gameplay, product, comedy,
storytelling, silent_art, finance, etc.), `output` dimensions (`1080x1920` or `1920x1080`),
optional `asset_catalog_path`, and run:
  python -m motionlab plan --job jobs/my_tutorial.json --creative-mode director --output runs
  python -m motionlab edit --job jobs/my_tutorial.json --creative-mode director --offline --output runs
  python -m motionlab validate --run runs/<run_id>
